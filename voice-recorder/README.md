# 소리 감지 녹음기 (SoundCatch)

안 쓰는 안드로이드 폰을 **"소리가 나면 자동 녹음 → 구글 드라이브에 자동 업로드"** 하는 녹음기로 만드는 앱.

- 조용할 땐 대기, 소리가 나면 녹음 (소리 나기 2초 전부터 담아서 첫마디가 안 잘림)
- 소리가 10초 동안 없으면 파일을 닫고 바로 드라이브로 업로드
- 드라이브 `폰녹음/날짜/` 폴더에 `2026-10-24_14-35-12_1m05s.m4a` 형식으로 저장
- 화면을 꺼도 동작, 인터넷이 끊기면 폰에 모아 뒀다가 연결되면 올림

---

## 1. 드라이브 받는 쪽 만들기 (PC에서 5분, 한 번만)

1. https://script.google.com → **새 프로젝트**
2. 기존 코드를 지우고 [`google-apps-script/Code.gs`](google-apps-script/Code.gs) 내용을 붙여넣기
3. 맨 위 `const SECRET = 'CHANGE_ME';` 를 나만 아는 비밀번호로 바꾸고 저장 (Ctrl+S)
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인 (경고가 나오면 *고급 → (안전하지 않음)으로 이동 → 허용*)
6. 나온 **웹 앱 URL**(`…/exec`)을 복사해서 카톡 '나와의 채팅' 등으로 녹음용 폰에 보내기

> 스크립트 코드를 고친 뒤에는 **배포 관리 → 연필 → 버전: 새 버전 → 배포** 해야 같은 주소에 반영된다.

## 2. 녹음용 폰에 앱 설치

1. 녹음용 폰 브라우저로 열기:
   `https://github.com/haesung-bot/minesweeper-craft-privacy/releases/download/voice-recorder-latest/soundcatch.apk`
2. 다운로드한 파일 열기 → "출처를 알 수 없는 앱" 허용 → 설치
   (Play 프로텍트 경고가 나오면 *세부정보 → 무시하고 설치*)

## 3. 앱 설정

1. **붙여넣기**로 웹 앱 주소 넣기 → 비밀번호 입력 → **연결 테스트**에서 ✅ 확인
2. **녹음 대기 시작** → 마이크·알림 권한 허용
3. **배터리 최적화에서 빼기** (삼성은 *설정 → 배터리 → 백그라운드 사용 제한 → 절전 예외 앱*에도 추가)
4. 충전기에 꽂아서 원하는 곳에 두기

가운데 막대로 감도를 맞춘다: 막대가 **빨간 선**을 넘으면 녹음이 시작된다.
조용한데도 자꾸 녹음되면 감도를 낮추고, 작은 소리가 안 잡히면 높인다.

## 설정 값

| 항목 | 기본값 | 설명 |
|---|---|---|
| 감도 | 6 / 10 | 주변 소음보다 얼마나 커야 녹음할지 (높을수록 민감) |
| 소리 멈춘 뒤 계속 녹음 | 10초 | 이 시간 동안 조용하면 파일을 닫음 |
| 미리 담기 | 2초 | 소리 나기 전 부분을 함께 저장 |
| 파일 최대 길이 | 10분 | 소리가 길게 이어지면 나눠서 저장 |
| 와이파이에서만 업로드 | 켬 | 모바일 데이터 사용 방지 |
| 업로드 후 폰에서 삭제 | 켬 | 끄면 `uploaded/`에 보관 (공간 부족 시 오래된 것부터 정리) |
| 재부팅 후 자동 시작 | 켬 | 안드로이드 13 이하는 자동, 14 이상은 알림을 한 번 탭 |

## 알아 둘 점

- 녹음 대기 중에는 상단 알림과 마이크 표시가 항상 보인다 (안드로이드 규칙).
- **다른 사람들끼리 나누는 대화를 그 대화에 참여하지 않은 채 몰래 녹음하는 것은 불법이다(통신비밀보호법).**
  본인이 참여하는 대화, 동의를 받은 녹음, 생활 소음·아기·반려동물 소리 확인 같은 용도로 쓸 것.
- `signing/soundcatch.p12` 는 공개 저장소에 있는 키라 보안용이 아니라 **업데이트 덮어 설치용**이다.
  플레이스토어에 올리려면 새 키를 만들어 비공개로 보관해야 한다.
- 업로드가 5번 연속 실패한 파일은 보류(`failed/`)로 옮겨진다. **지금 업로드**를 누르면 다시 시도한다.

## 개발

- `voice-recorder/` 아래를 고쳐서 `voice-recorder` 브랜치에 푸시하면 GitHub Actions가
  테스트·린트·빌드 후 릴리스 `voice-recorder-latest`의 APK를 교체한다 (버전 코드 = 빌드 번호라 덮어 설치됨).
- PC에서 빌드: Android Studio → Open → `voice-recorder` 폴더 → `.\gradlew.bat test assembleRelease`

```
app/src/main/java/com/soundcatch/recorder/
  SoundDetector.kt   소리 감지 (주변 소음 추적, 시작/끝/분할 판단) — 순수 Kotlin, 단위 테스트 있음
  AacFileWriter.kt   PCM → AAC(.m4a) 저장
  RecorderService.kt 포그라운드 서비스: 마이크 → 감지 → 파일 → 업로드
  Uploader.kt        업로드 큐 (재시도·보류·삭제)
  DriveUploader.kt   Apps Script 웹앱 전송 프로토콜 — 순수 Kotlin, 단위 테스트 있음
  MainActivity.kt    화면 (상태·소리 막대·설정)
google-apps-script/Code.gs  드라이브에 저장하는 웹앱
```
