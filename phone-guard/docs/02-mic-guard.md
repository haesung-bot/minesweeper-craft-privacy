# 02. 마이크 파고들기 — "내 마이크가 해킹당할 수 있나?"

## 0. 코드 없이, 지금 당장 확인하는 법

안드로이드가 이미 꽤 강한 방어를 기본으로 해 준다. 코드를 보기 전에 먼저 이것부터 확인한다.

1. **최근 24시간 마이크 사용 앱 보기**
   `설정` → `보안 및 개인정보 보호` → `권한 사용 기록`(또는 `개인정보 보호 대시보드`)
   → `마이크` → 최근에 실제로 마이크를 쓴 앱 목록이 나온다.
   이건 OS가 직접 주는 정보라 **PhoneGuard 같은 일반 앱은 볼 수 없는 더 정확한 기록**이다.
2. **지금 이 순간 마이크가 켜져 있는지**
   상태 표시줄에 초록색 점(Android 12+)이 뜨면 마이크나 카메라가 사용 중이라는 뜻이다.
3. **권한 관리자에서 통째로 끄기**
   `설정` → `권한 관리자` → `마이크` → 의심스러운 앱을 `허용 안 함`으로.
   빠른 설정 패널의 **마이크 차단** 토글을 켜면 모든 앱의 마이크를 한 번에 끌 수 있다.

> 결론: 일반 사용자에게 가장 현실적인 위협은 "국가급 해킹"이 아니라
> **"내가 권한을 준 걸 잊은 평범한 앱"**이다. 위 3단계만으로 대부분 커버된다.

---

## 1. PhoneGuard의 "마이크 권한 점검"이 하는 일 (확실히 동작)

`MicRiskAnalyzer` (순수 Kotlin, PC에서 테스트 가능)가 권한 **조합**을 본다.
마이크 권한 자체는 흔해서(전화, 음성메모, 통화앱) 점수가 낮고, 설명되지 않는 조합일수록 올라간다.

| 조합 | 점수 | 의미 |
|---|---|---|
| 마이크만 | 10 (LOW) | 흔한 경우. 통화·녹음 앱 등 |
| 마이크 + 인터넷 | 35 (MEDIUM) | 들은 걸 밖으로 보낼 수 있음 |
| 마이크 + 백그라운드 서비스(통화 권한 없이) | 30 (MEDIUM) | 전화앱이 아닌데 화면 꺼져도 마이크를 씀 |
| 마이크 + 오버레이/접근성 | 30 (MEDIUM) | 화면 위에 뭔가 그리면서 동시에 들을 수 있음 |
| 위 조합이 다 겹침 | 75 (HIGH) | 가장 의심스러운 패턴 |

이건 `./gradlew test`로 어디서나 검증 가능하고, 이 환경에서 이미 통과를 확인했다.

## 2. "실시간 마이크 감시" (실험적 — 꼭 내 폰에서 검증)

버튼을 누르면 PhoneGuard가 열려 있는 동안, **다른 앱이 마이크를 켜거나 끄는 순간**을
화면에 바로 띄운다. 안드로이드가 "마이크/카메라 사용중 표시" 앱들을 위해 공개해 둔
`AppOpsManager` API를 그대로 쓴다.

**중요: PhoneGuard는 이 기능 때문에 마이크 권한을 요청하지 않는다.**
내가 녹음하는 게 아니라 남의 녹음 시작/종료 "신호"만 감시하기 때문이다.

### 정직한 한계 (내 PC/서버에서는 검증 불가능해서, 꼭 실기기로 확인할 것)

| 항목 | 설명 |
|---|---|
| 지원 버전 | Android 11(API 30) 이상만 동작. 이하 기기는 자동으로 "지원 안 됨" 메시지 |
| 패키지명 노출 | 제조사/OS 버전에 따라 다른 앱의 패키지명이 가려질 수 있음 |
| 감시 범위 | PhoneGuard 화면이 열려 있는 동안만. 끄면 감시도 멈춘다 |
| 과거 기록 | "어제 누가 썼는지"는 못 본다 — 그건 OS 전용 정보라 0단계의 설정 메뉴로만 확인 가능 |

### 🧪 현장 테스트 (내 폰에서 꼭 해볼 것)

1. PhoneGuard에서 `실시간 마이크 감시 시작` 누르기
2. 다른 앱(예: 기본 카메라 앱의 동영상 녹화, 또는 음성 녹음 앱)을 열어서 녹음 버튼 누르기
3. PhoneGuard 화면에 `[실시간] (앱 이름) 마이크 사용 🔴 시작` 이 뜨는지 확인
4. 녹음을 멈추면 `⚪ 종료` 가 뜨는지 확인

| 결과 | 의미 |
|---|---|
| 정확히 뜬다 | 이 기능이 내 폰에서 실제로 작동한다 ✅ |
| 패키지명은 가려지고 "뭔가 켜졌다"만 뜬다 | 제조사가 다른 앱 식별을 막아둔 것 — 그 자체로 괜찮은 보안 설계다 |
| "지원되지 않아요" 메시지가 뜬다 | 이 기기/OS 버전에서는 이 방식이 막혀 있다는 뜻. 0단계 설정 메뉴를 쓴다 |
| 앱이 즉시 꺼진다(크래시) | 버그 — 바로 알려달라. SecurityException을 못 잡은 경우일 수 있다 |
